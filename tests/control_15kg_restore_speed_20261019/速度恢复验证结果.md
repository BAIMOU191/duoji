# 15kg 恢复原运动默认值

日期：2026-10-19。按用户实测反馈撤销V/A/D降速。仅修改15kg的`Application/A_Config.h`，速度163→234°/s，加减速度1400→5600°/s²。惯量比1.0、反馈修正、到位/保持分离、200ms稳定判据、50ms交接及连续T=0策略全部保留。

源文件起止哈希共核对482份：本轮仅上述配置头文件变化。参数地址、运行时生效规则、保护逻辑和额定上限没有变化。

## 同一算法、不同运动强度的对比

| 指标 | 上一版163/1400/1400 | 恢复234/5600/5600 |
|---|---:|---:|
| 惯量4、大换向到位事件，ms | 1688 | 1385 |
| 同场景最后目标过冲，° | 3.10 | 6.77 |

| 70场景往返换侧计数 | 107 | 95 |
| 全351场景fault事件 | 0 | 19 |
| 全351场景堵转事件 | 1 | 4 |

响应速度提高，但并非所有指标改善。主矩阵包含重载、变载、失配和快速反复换向，保护故障事件增加是真实的仿真结果，不是编译或参数接口故障。模型仍采用假设的机械与电气参数，不能把事件数直接解释为实机故障概率。

保留的固定惯量带宽约束、150ms最短运动时间、连续T=0目标展望仍会影响响应；恢复V/A/D不等于完全退回原版的所有动态行为。200ms稳定和50ms混合主要影响进入保持律，到位事件仍使用独立资格判据。
