# ADC 15kg 控制优化实测版

日期：2026-10-19。仅修改本工程的 `Application/A_Config.h`、`Application/A_Servo.c`、`Common/C_Pos_Ctrl.c/.h`。其他型号没有同步。

## 本版行为

- 位置/速度条件满足约20ms可锁存到位事件；位置锚点稳定200ms后，用50ms从收尾律渐变到保持律。
- Stop查询当前是否真正处于HOLD；每条新规划清理到位资格，零位移新目标也可完成。
- 补充位置修正对应的kv电压反馈；固定惯量比用于观测器模型和外环带宽，不放大加速度前馈。
- 对多次连续、同向且接收间隔匹配的普通T=0目标延长规划展望；暂停、Stop、重同步、显式T和超过300ms断流会清理该状态。
- 保留原始电流、堵转、温度等保护，未加入DOB或反电势软限幅；保持P/I默认值仍为80/0。

## 本次实测参数

| 参数 | 本版默认 | 设置位置/说明 |
|---|---:|---|
| 最高速度 | 163°/s | 现有Flash地址0x30、SRAM地址0x85 |
| 最大加速度 | 1400°/s² | 现有Flash地址0x31、SRAM地址0x86 |
| 最大减速度 | 1400°/s² | 现有Flash地址0x32、SRAM地址0x87 |
| S曲线平滑时间 | 50ms | 原有参数 |
| 最短运动时间 | 150ms | 原有参数 |
| 固定惯量比 | 1.0 | `A_Config.h`中的`TUNE_LOAD_RATIO_X10=10U`，数值放大10倍；修改需重新编译 |
| 到位精度 | ±0.5° | 原有参数 |

速度163是此前仿真163.8°/s按现有整数参数单位向下取整后的值。加减速度通过现有参数直接设置，没有隐藏比例缩放：例如SRAM写入5000°/s²，规划器实际使用5000°/s²。额定上限仍为260°/s、8000°/s²、8000°/s²；设为0仍表示使用额定值。惯量比不占用新的Flash字段或串口地址。

## 实测文件与启动参数

正常闭环固件：`obj/CH32V00X_APP.hex`、`obj/CH32V00X_APP.bin`，同时更新了对应ELF/MAP/LST，均由当前源代码全量构建。没有烧录设备。

正常/标定两种模式已分别编译；标定模式文件只保留在测试输出目录，`obj`中提供的是正常控制固件。`User/main.c`的`APP_MODE_CALIB`保持注释状态。

现有配置加载规则会在固件指纹变化时恢复这份固件的默认参数，保留原ID和波特率；其余参数（含校准与脉冲边界）按原有初始化逻辑恢复默认。本次没有改动这套规则。刷入后先查询V/A/D是否为163/1400/1400，并按实际机构核对模式和位置校准。

优先观察小角度T=0连续输入、大角度换向、到位后保持、暂停/继续和外力撤除后的位置变化。连续T=0的平顺性以额外跟随滞后为代价；持续外载和外推后的保持偏差尚未完全解决，不能将仿真结果当作实机精度承诺。
