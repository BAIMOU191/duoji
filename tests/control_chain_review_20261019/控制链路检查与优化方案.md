## 0. 结论摘要

1. **标定与实物一致、空载时，链路是好的**：三版大阶跃、换向、连续指令的过冲 ≤0.16°，到位误差 ≤0.16°，无振荡。
2. **问题都出在"实物 ≠ 标定模型"的时候**。舵机一旦带上臂（惯量 2~8 倍电机）、重力或变化负载，或者标定本身有 ±15% 误差，就会出现下面五类"走走停停/不稳"：

| # | 现象 | 根因（一句话） | 证据 |
|---|---|---|---|
| A | 大动作末端过冲 4~18°，到位后来回摆 2~6 次，最后停在窗外 | 规划器的 A/D 按空载额定能力给，带惯量/重力后减速根本做不到；控制增益也只按电机自身惯量设计 | 表 3-2、图 01 |
| B | 重载快速换向时**过流保护卸力，手臂直接掉下来** | 减速做不到→冲过目标→全压反接制动，电流 (U+反电势)/R 超 3A 持续 30ms→卸力；限流环同时把 PWM 上限对称压低，进一步削弱刹车 | 表 3-3、图 02 |
| C | 连续指令"一段一段"：每个目标都停一下；快一点的连续指令严重滞后、变形 | 规划器对每个目标都"停到目标点"规划，最短运动时间 150ms 又套在连续指令上 | 表 3-5、图 03/04 |
| D | 到位后自己慢慢蠕出到位窗（无外力），或外力撤掉后被推开 5° | 积分在运动中吃进了模型误差/动态力，到位判"静止"的门槛是 3.8°/s，蠕动中就被判到位，保持律把这个错的积分永久冻结 | 表 3-6、图 05 |
| E | 慢速（<约3°/s）运动一走一停 | 静摩擦 fs 比动摩擦 fc 大 1.7~3.3 倍，现有摩擦补偿在低于速度噪声底(3.78°/s)时基本不起作用 | 表 3-7、图 06 |

3. **不同标定值的适配**：主算法确实随标定自动换算，匹配时 τ=6~45ms、高摩擦、噪声大的合成电机都能正常工作。但有三处"只适应某一段标定值"：
   - 编译期：延迟 >4.17ms 或最小步长 >33 厘度直接编不过（而标定固件允许到 8ms / 80 厘度）；
   - 等效刚度、保持阻尼随标定变化 2~3 倍（20kg 抗负载刚度是 30kg 的 2.6 倍；15kg 保持阻尼最差）；
   - 对标定误差敏感：kv ±15% 或 ka +50% 就会在**无外载**时停在窗外 0.6~1.4°。
4. **方案**（第 5 节）按层改，不打补丁：轨迹层"可行性规划 + 连续指令插补通道"；控制层"负载惯量比 + 扰动补偿 + 模型电流钳位"；到位层"位置静止判据 + 保持力可纠错 + 统一阻尼"；保护层与标定层配套。原型在同一套 70 例带载点到点仿真里：

## 1. 仿真方法

**被控对象**（`sim/sim.c`，10µs 积分）：

- 电机侧：电压域模型 `ka·a = u(t−d) − kv·v − fc·sgn(v) − 齿轮力`，静止且净力 < fs 时粘住（Karnopp）。kv/ka/fc/fs/延迟 取各工程标定值，可按比例偏离（模拟标定误差）。
- 齿轮 + 负载侧：负载惯量 = r × 电机侧惯量，齿轮刚度按 40~60Hz 谐振给、带 8% 阻尼，可加齿隙；负载侧受重力 `G·sin(θ−竖直)`（倒立摆型）及各种外载（阶跃、随机、推一下）。
- 电位器测负载侧（输出轴），按真实流程做 1ms 块均值、加噪声（σ=标定噪声/3）、可加位置波纹，再按 Q4 ADC 量化，由生产代码 `A_Encoder_Read` 换算。
- 绕组电流 `(u − kv·v)/R`，**R 取 3.2Ω（三型号同一假设，未实测）**；电流有效条件与驱动层一致（占空比 ≥268/2400）。母线 7.6V，可设内阻/低压。
- 控制侧：`A_Servo / 规划器 / 控制器 / 观测器 / A_Protect / A_Config` 的生产源码原样编进同一个程序（只替换硬件桩），1ms 一拍，保护 10ms 一拍。

**指令场景**：大阶跃(+90°后−180°)、中途换向(180°每400ms)、到位后换向(90°每1.2s)、带时间90°/2s、PWM 50Hz 斜坡、总线 50ms/T0、100ms/T100、200ms/T200 连续目标、20ms 一帧的正弦跟踪、慢速(0.5~16°/s)、0.27°小步、到位后被推一下。

**负载场景**：空载；惯量 2/4/8 倍；重力 20/30/40/60% 标定电压（配 4~8 倍惯量）；运动中 ±3V 负载阶跃；约 2Hz 的随机负载；齿隙 0.6°；母线 6.4V；以及标定误差（ka×0.7/1.5、kv×0.85/1.15、摩擦×0.5/1.6、fs×2、延迟×0.6/1.5、噪声×2.5、电位器波纹）。

**指标**：过冲（参考停后越过目标的最大量）、来回摆次数（越过目标 ±0.3° 的换向次数）、终点误差、跟踪误差、走停次数（实际速度先到参考的 50% 又掉到 15% 以下 ≥10ms）、流式速度最小值/纹波、过流卸力/堵转放弃次数。

**局限**：齿轮、摩擦、重力、电流都是理想化模型；R、齿轮刚度、负载惯量是假设值；没有模拟温升和 Flash 写入停顿。结论用于判断机理和量级，最终要靠台架数据确认。

## 4. 不同标定值的适配性

### 4.1 编译期就拒绝的标定（用合成标定实测编译）

| 合成标定 | 结果 | 原因 |
|---|---|---|
| 延迟 4500µs | **编译失败** "Controller bandwidths violate constraints" | `A_Config.h:92`：ωp=20 固定，要求 4·20 ≤ ωv=1/(3·延迟)，即延迟 ≤4.17ms；而标定固件允许到 8ms、`A_Config.h:89` 允许 <7ms |
| 最小可靠位移 34 / 40 厘度 | **编译失败** "Invalid default motion/hold parameters" | `A_Config.h:94`：默认到位精度 50 < 1.5×最小步长；标定固件允许到 80 |
| τ=12ms、τ=6ms 的快电机 | 编译通过、仿真正常 | 但标定固件自检 `A_Calib_Min.c:586`（ka·120 ≥ 2kv ⇒ τ ≥16.7ms）会直接 `#error`；30kg 自己 τ=17.8ms 只有 7% 余量 |

### 4.2 匹配时能否工作（合成电机，30kg 代码）

τ=12ms 快电机、τ=45ms 慢电机、高摩擦（fc 450/fs 1000mV）、噪声 14 厘度：空载各场景过冲 ≤0.19°，都能工作。**算法本身确实随标定换算**，不存在只适配某一份标定的硬编码。但带惯量后 τ=45ms 的电机过冲 12°，敏感性和三款现有电机一样。

### 4.3 同一套"设计带宽"，换算后的实际性能差别很大

| 量 | 15kg | 20kg | 30kg | 说明 |
|---|---|---|---|---|
| ωv (rad/s) | 103 | 120 | 103 | 由延迟决定 |
| Kv = ka·ωv − kv，mV/(厘度/s) | 0.45 | **0.86** | **0.33** | 30kg τ 短，kv 吃掉了大部分 |
| 实际位置带宽 ωp·Kv/(Kv+kv) | 12.9 | 14.3 | 9.1 | 设计值 20 |
| 位置刚度 Kv·ωp，V/° | 0.91 | 1.71 | 0.66 | +3V 负载阶跃下偏差 2.9/1.7/3.1° |
| 保持阻尼比（P=80，空载） | 0.61 | 0.69 | 0.95 | 只靠反电势 kv |
| 保持阻尼比（4 倍惯量） | 0.27 | 0.31 | 0.43 | 15kg 最容易保持振荡 |
| 速度噪声底 | 378 | 378 | 378 | = 21Hz×3×噪声；噪声 14 的电机会到 882（8.8°/s），低速补偿/捕获门槛全跟着变 |

### 4.4 对标定误差的敏感性

见 3.6：kv ±15% 或 ka +50%（同型号个体差、温升都可能到这个量级）就能让无外载的到位误差超出 0.5° 精度。延迟、噪声、摩擦 ±50% 影响不大。

### 4.5 保护常数不随型号

`TORQUE_STALL_CURRENT_MA=2000`、过流 3A/30ms、"扭矩↔电流"换算三型号共用，没有从标定导出（前次审查也指出）。绕组电阻 R 从没测过，而它决定了刹车时的电流。

## 5. 优化方案

原则：**让控制器知道"实物现在能做到什么"，而不是在出事后补救**。按层改，每层解决一类根因；层与层之间用明确的量传递（负载惯量比 J、负载估计 L̂、可用电压/电流）。

### A 轨迹层

**A1 可行性规划（解决现象 A/B）** —— 每次 `Servo_Move` 前，用当前能力收紧本段 V/A/D：

```
U_avail = min(0.85·可用电压, R·I_max)           // 电压留 15% 给反馈；电流上限见 B4
L       = 负载估计的慢包络（托举力低通 τ≈0.3s，再取衰减峰值 τ≈2s）
A_eff   = min(A_用户, (U_avail − L − fc) / (ka·(1+J)))
D_eff   = 同上
V_eff   = min(V_用户, (0.85·可用电压 − L − fc) / kv)
J_eff   = max(A_eff, D_eff) / 平滑时间            // 平滑时间不变
```

并在运动中每 10ms 复核一次：负载估计变大使剩余减速不可行时，用新能力从当前参考状态重规划到同一目标（复用现有 `C_Traj_Plan` 的接管机制）。原型里这一项把"重力 60%+惯量×8"的过冲从 21° 降到 0，也让电流不再冲 3A。

代价：负载按近期最大值、不分方向，重载时偏慢（60% 重力下约 48°/s）。可以再按"重力助推还是阻碍本段运动"分方向放开；能力受限的慢动作还会被现有堵转判据误判 2~3 次，需要 D 节的堵转改动配套。

**A2 连续指令通道（解决现象 C）** —— 识别连续流（相邻目标间隔 ≤100ms 且连续出现），走插补而不是逐点停：参考 = 相邻目标线性插补（延迟一帧），参考速度 = 目标差/间隔，再经一个宽度=间隔的滑动平均给出加速度并限 jerk；流断开（超过 2 个间隔没新目标）后用现有 S 曲线规划停到最后一个目标。孤立目标仍走现有规划器。预期滞后约 1.5 帧（20ms 帧时 1Hz±30° 约 5°，现状 59°）。

> 注：10-14 曾删除过 Follow 模式。这次的数据说明逐点 S 曲线本身不适合连续流，只调 Tm 解决不了 20ms 级的流。

**A2'（A2 的最小替代）** —— 如果暂不做插补：连续流时规划时间取 max(T, 2×实测间隔)，且最短运动时间只用于"从静止起步的孤立动作"。原型验证：200ms/T200 流参考不再停（最小速度 0→0.98），0.5Hz 正弦滞后 12.5°→4.5°。但它挡不住快速流（图 04 那种）。

**A3** 修掉 `n<2` 跳过接管（`C_Traj_Planner.c:477`）；运行中降 J 时把新限值推迟到当前接管结束后生效（前次审查问题 7、8）。

### B 控制层

**B1 负载惯量比 J（所有带载问题的前提）**：
- 用在：前馈 `ka·(1+J)·a`、观测器模型 ka、外环增益 `ωp ≤ ωv/(4(1+J))`、`ωi ≤ ωp`；Kv 保持按空载算（它受电位器噪声限制）。
- 来源：参数（每个关节写一次），可选在线辨识（运动中观测器扰动对参考加速度做回归，每段运动更新一次，单次最多改 50%）。
- **宁大勿小**。原型对惯量估计错误的鲁棒性：

| 实际惯量 | 模型 J=0 | J=2 | J=4 | J=8 |
|---|---|---|---|---|
| 0（空载） | 0.13° / 0 次 | 1.00° / 1 | 0.68° / 1 | 1.75° / 1 |
| 2 | 1.78° / 4 | 0.25° / 0 | 0.18° / 0 | 0.70° / 1 |
| 4 | **5.06° / 8** | 2.21° / 1 | 0.19° / 0 | 0.98° / 0 |
| 8 | **7.26° / 4** | 5.57° / 4 | 4.32° / 1 | 0.66° / 0 |

（30kg 阶跃，过冲 / 来回摆次数，全部方案项打开）。估小 2 倍以上时扰动补偿会把模型误差当负载反复补，来回摆比现状还多（另一版本里出现过持续振荡）；估大只是空载时过冲多 0.5~1.6°。所以默认值按"带臂关节取 3~4、空载/末端关节取 0~1"，在线辨识从偏大的值往下收。

> 10-15 曾做过 `TUNE_LOAD_INERTIA_X10`（台架上 r=4 有效，后来移除）。这次的差别是：J 同时进规划能力（A1）和扰动补偿（B2），而且明确"宁大勿小"。

**B2 扰动观测补偿**：`u += LPF(d̂)`（观测器已有的扰动估计，低通约 40 rad/s，粘住时不更新，HOLD 中冻结）；积分只修残差。负载变化由 25ms 级的扰动补偿接住，不再等 0.2s 的积分。**必须在 B1 之后上**（见上表）。

**B3 位置修正量同时走模型**：`u_fb = Kv·(v_cmd − v̂) + kv·ωp·e`。实际位置带宽回到设计值 ωp，抗负载刚度不再随 τ 变化 2.6 倍（4.3 节）。改动一行，风险小。

**B4 模型电流钳位（替代对称限流）**：每拍把输出夹在 `kv·v̂ ± R·I_max` 内（I_max 取略低于限流阈值，如 1.9A）。刹车时控制器自己就不会冲出 3A，也不需要保护层去压 PWM 上限。需要 R：在标定固件里加一步（低占空比堵转测 U/I，电流此时可测的段：≥11% 占空比）。

**B5 低速颤振（解决现象 E，需上机验证）**：参考在动且慢于速度噪声底时，叠加 ±(0.6~1.0)·fs、250Hz 方波（平均为 0）。仿真：0.5~2°/s 的走停次数从 2~26 次降到 0；但实物 fs 为标定 2 倍时不够。代价是可听的嗡声和齿面微动磨损。另外仿真表明：简单地"低速给满 fc 前馈 + 按参考速度起转"会让走停次数增加 2~10 倍，不要这样改。

### C 到位/保持层

**C1 静止判据改用位置**：捕获要求"锚点在 N ms 内没挪过最小可靠位移"（`still_ms`，现成的），不用 3.78°/s 的速度噪声底。原型（N=100ms）：15/20kg 在 kv/ka 误差、惯量×4 场景下的终点误差从 0.6~1.4° 降到多数 <0.5°；30kg 改善有限（Kv 小，SETTLE 收得慢）。"上报到位"和"转入保持律"可以分开：前者照旧按到位精度，后者等积分收敛。

**C2 保持力不能永久冻结一个错值**：到位时继承的积分不一定是真实负载（3.6 节两种来源：运动中的模型误差、SETTLE 里的动态力）。原则：**轴在保持中朝"保持力推的方向"自己移动，说明保持力错了，就按移动量把它往回减**；被外力推开（移动方向与保持力相反）则保留。这和 I>0 的保持积分不同：它不需要误差先超出窗口、也不需要先克服静摩擦。
> 这一项和 10-15/16 试过又撤掉的"分级释放/速度积分"同类，需要你决定是否再走这条路；如果坚持纯 PI 保持，至少要配合 C1，并接受 3.4 节"撤载后偏 5°"的语义。

**C3 保持阻尼按 ζ 统一**：`Kd = max(0, 2ζ·√(Kh·ka(1+J)) − kv)`，ζ 取 0.7，在 HOLD 全程连续生效（不按 ex≠0 门控，避免当初"出窗被反推"的问题）。空载 30kg 自动为 0（反电势已够），15kg 和带惯量时自动补上。

### D 保护协同

- 有了 B4，限流环改为只监视（或只在持续过流时缓降），**不再对称压低 PWM 上限**。
- 过流故障判据排除"控制器主动刹车、且电流在钳位值以内"的情况；真正的硬件过流仍按现有 3A/30ms。卸力会让重力负载掉落，代价远大于短时过流。
- 堵转判据的参考位移阈值随本段规划速度缩放（前次审查问题 5），避免能力受限的慢速运动被误判。

### E 标定一致性

- 把 `A_Config.h:92,94` 的编译期断言改成运行时钳位（ωp=min(20, ωv/4)；到位精度下限按 1.5×最小步长自动抬高），或让标定固件自检用同一组界限，二者一致。
- 标定固件自检 `ka·120 ≥ 2kv` 改用实际 ωv（1/(3·延迟)），或去掉（控制器已有 Kv 下限）。
- 标定固件增测绕组电阻 R（B4 需要），并由 R 和堵转电流导出保护常数，三型号不再共用 2000mA。
- 速度噪声底不要再当作低速判据的来源（C1、B5 用位置/参考速度判）。

## 7. 建议实施顺序与上机验证

1. **B3 + B4 + D（保护协同）+ E（断言/自检一致）**：改动小、无副作用，先消除"卸力掉臂"和型号间刚度差。上机：重臂快速换向，记录电流、PWM 上限、是否卸力。
2. **B1（J 参数）+ A1（可行性规划，含运动中复核）**：消除过冲和来回摆的主因。上机：每个关节用 J=0/2/4 各做一次大阶跃，看过冲；确认"宁大勿小"。
3. **C1 + C3**，再决定 C2：先用位置判静止，看无外载蠕出窗口是否消失。
4. **A2（或先 A2'）**：用实际上位机的发送节奏（20ms/50ms/100ms，T=0/T=间隔）测速度纹波和滞后。
5. **B2**：在 J 定好之后再开，先把低通压到 20 rad/s 观察，再升到 40。
6. **B5**：单独评估噪声与磨损。

每一步都建议记录 FireWater：目标、参考、实际、参考速度、观测速度、输出、积分、状态、电流、PWM 上限。
