# 30kg 小角度到位回摆优化

## 对应现象

用户确认现象是“到位后前后晃动一下”。最终修改针对首次到位后的反向修正，未采用前期针对慢速走走停停的摩擦门限实验。

基线参数：速度92%、位置分辨率30厘度、观测器11Hz、位置环9rad/s、速度环22rad/s、保持刚度12、减速平滑40、小位移最短50ms。标定输入与上述参数全部保留。

## 原因与修改

原代码在进入POSCTRL_HOLD时直接锁存held，立即允许保持弹簧参与输出。但到位判据的窗口为0.75°、速度门限15°/s，连续满足20ms即可进入；此时轴可能仍在首次停车收尾，保持弹簧会进一步加大反向回推。

修改后需要同时满足轨迹结束、已进入HOLD、位置误差不大于静止捕获窗0.45°、观测速度不大于2.46°/s，才允许首次锁存held。首次停车仍由原位置/速度环和摩擦补偿完成。锁存后，被外力推开时继续保留原保持刚度；该条件不依赖quiet，因此不会仅因持续负载禁用静音就禁止建立保持能力。

这项修改减轻反向修正冲击，不会消除之前已经形成的超调。未通过降速或放大死区来掩盖回摆。

## 仿真对比

末端阶段共比较7种方案，每种55个工况。角度包括±1.35°、±6.75°、±13.5°、±20.25°等；覆盖标称对象、时间常数增加27%或降低36%、恒定负载、额外2ms延迟。

下表采用时间常数比模型大27%的工况，对应单次标定中两方向动态响应不一致的敏感性测试。均为从1500附近发T0000指令；仿真角度坐标按当前270°标度。

| 工况 | 反向峰值速度，旧→新 °/s | 回退距离，旧→新 ° | 首次超调，旧→新 ° | 最终误差绝对值，旧→新 ° | ±0.5°稳定时间，旧→新 ms |
|---|---|---|---|---|---|
| +13.5° | 12.16 → 7.30 | 0.757 → 0.630 | 0.941 → 0.941 | 0.184 → 0.310 | 257 → 261 |
| +20.25° | 12.46 → 7.08 | 0.778 → 0.648 | 0.959 → 0.959 | 0.181 → 0.310 | 304 → 309 |
| -13.5° | 12.99 → 6.83 | 0.657 → 0.531 | 见JSON | 0.156 → 0.281 | 240 → 246 |

典型反向峰值下降约40%～47%，回退距离减少约17%～19%。代价是上述工况的最终残差略大，仍在既有静止捕获窗内；±0.5°稳定时间增加4～6ms。原参考轨迹时长不变。所有这些数据是仿真结果，不能替代实机验证。

相比之下，只降低保持刚度对回摆冲击的改善较小，同时会影响最终抗外力能力；增加运动平滑度会延长部分小角度轨迹，故本轮没有采用。

## 验证

- WCH固件编译通过。
- 33组回归与审计通过，包含新增arrival_soft，以及原有保持刚度、持续负载、卸载、保护和换向检查。
- 新增测试使用实际惯性增大27%的对象，约束反向修正峰值、参考时长、超调、最终误差和静止输出。旧控制器在正反两向均不能通过反向峰值检查，新控制器通过。
- 未烧录硬件，未覆盖工程obj中的固件。

## 文件及复现

`comparison.json`保存首轮6种方案及原始代码快照；`comparison_selected.json`保存最终基线/arm_settled对比。CSV保留代表工况完整的1ms位置、实际速度和PWM等波形。

在30kg工程目录，使用支持的Python和gcc运行：

```text
python tests/compare_arrival_bounce.py --baseline-report tests/results/arrival_bounce/comparison_selected.json --variants baseline arm_settled
python tests/run.py quick
```

前期慢速实验在`tests/results/small_motion/`，对应不同现象，未写入最终控制代码。

## 实机范围

仿真采用一阶对象、起转219/235PWM、±5.21厘度均匀位置噪声；没有齿轮弹性、齿隙接触冲击或独立机械振铃模型。用户尚未提供这次回摆的精确指令和同步日志，因而只能说明代码存在可减轻回摆的机制，不能认定已彻底解决实机现象。
